# Constraints

This file says what limits the project works within, set by the owner's situation and not by choice, each with where it comes from and whether it can be moved. The choices a limit drove are recorded in the files they concern, and those files cite the limit.

## Client-neutral source boundary

Every resident admitted to Design Studio contains no client-identifying content, engagement material, private library index, private token dump, or operator-specific path. <!-- LM-01 -->

Comes from: the source material extracted into Design Studio may originate in client-engagement environments.

Negotiable: no.

Revisit when: the source boundary and publication posture change with the Designer's approval.
