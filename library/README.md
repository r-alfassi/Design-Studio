# Library

External, non-binding design/UX resources worth returning to — a shelf, not a
procedure and not a convention. Distinct from the other two directories on
purpose, not by convenience:

- **Not `skills/`** — nothing here is executed. A library resident is read
  and drawn from; it doesn't run.
- **Not `references/`** — that directory holds this repo's own operational
  how-tos (tool setup, connection config). A library resident is external
  authored material — a framework, pattern catalog, or methodology this repo
  didn't write and doesn't own.

Governs nothing. A resident earns its place by being genuinely worth
returning to, not by being the first hit on a search. Each resident is owned
by its original author — this repo adds a pointer and short application
notes, and does not rewrite or reproduce the source material at length.

Same shape and reasoning as the federation hall's own `library/` compartment
(non-binding learn-from resources, distinct from its binding `standards/`) —
adopted here for the same reason it holds there: a resource genuinely
different in kind from a procedure or a local how-to needs its own shelf, not
a home inside one that already means something narrower.
