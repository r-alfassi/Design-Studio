# Comuna role screens: right-to-left details and review text slipped through

Observed 2026-11-03 on Comuna (a Hebrew, right-to-left app), where the agent built eighteen screens from scratch in Figma in the product's own design, desktop and mobile, for three roles. The Designer reviewed them. This entry is evidence for R-34, for the `rtl` skill and for the sprint skill. It governs nothing.

What got through, and what the agent's own checks missed:

- **A column of hug-width children was packed to the left of its own column.** A name over its role in a list row, in the family's proposal screen, in both sizes. The row was correct and the column inside it was not, so "אור" ended at a different edge from "חבר בקבוצה". The `rtl` skill already named the hug-width row in a vertical frame, and the agent's audit searched for exactly the listed cases (left-aligned text, rows packed left) and found none. The rule had been written for rows and the mistake was one level down. The Designer found it by eye. Fixed by setting `counterAxisAlignItems` to `MAX` on six frames, and the rule in the Figma reference now says any vertical frame with hug-width children.
- **A ratio showed reversed.** `3 / 4` showed as `4 / 3` beside Hebrew. The reference already had the same cause for a time range. It was fixed with a left-to-right isolate on eleven values, after the agent saw it in a screenshot.
- **Review text sat inside the product frame.** A strip at the top of every screen said which role the screen was for. `standards/studio-presentation.md` says review text belongs in sibling chrome, but nothing checked it, and the Designer had to say so. Moved to a label above each frame, and an explanatory sentence in a card was cut.
- **Tall screens were reviewed at a size that hides the error.** A screenshot of a 1,500 px frame is shrunk to about a quarter, and one misaligned line disappears. Some of the agent's reviews were at that size.
- **A cleanup script was applied to pages that needed none.** The agent used the capture clean-up for personal data on two pages that held none, and it replaced real interface labels with placeholders. It was caught on the next look at the screenshot and the two pages were captured again. Not a studio finding, but a reminder that a rule meant for one kind of page is not applied to every page.

What changed because of it: `skills/rtl/scripts/figma/phase4-audit-built-rtl.js` reports a left-packed hug-width column, left-aligned Hebrew text, a row packed left, a bare ratio, and review text inside the frame. The agent ran it on all eighteen screens (clean) and on a copy with the defect put back (found it). The sprint skill has a right-to-left gate that requires the script, a look at 1:1 crops of each kind of component, and a read of every string in the frame alone. The audit skill points to the script. A requirement for the right-to-left gate is proposed and not yet added to `requirements.md`.
