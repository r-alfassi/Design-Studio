## Core

- `purpose.md`: Design Studio keeps reusable design craft separate from client engagements, so that projects can apply it without rebuilding or inheriting client context.
- `audience.md`: The Designer, Principal, and project agents use Design Studio to find reusable design craft without importing another project's decisions or client context.
- `scope.md`: Design Studio maintains reusable design craft and guides visual design work in a Figma file from a stated direction to a design ready for production, as a package a project imports; it does not hold client context, define a project's intent, assume any particular record system, move work into production, tune visuals in code, or take an active agent role.
- `constraints.md`: The source material that feeds Design Studio can contain client context, so every reusable resident remains client-neutral and passes an admission scan before it is added.
- `principles.md`: Explore freely and approve deliberately, no fixed authority between design and production, and a resident earns its place by beating none.
