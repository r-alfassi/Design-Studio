# F-001 — Treat the Figma file as a maintained shared artifact

- **Status:** closed 2026-08-30 after corrective pass
- **Observed:** 2026-08-30, the S-02 Available-times correction created a new
  peer frame beside the legacy proposal without first reconciling the existing
  page section, hierarchy, or authority cues. The visual screen improved, but
  the file became harder to navigate and contained competing-looking work.
- **Operating correction:** before a Figma write, inspect the relevant page and
  neighbouring section. Reuse or revise the existing current node whenever

  label the old node as historic or move it to the existing historic area. End

  compare each candidate's distinct state treatment and carry forward stronger
  reusable structure rather than treating archive as an evaluation result.
