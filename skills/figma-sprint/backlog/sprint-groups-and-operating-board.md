# F-006 - Alternate the layout axes and keep a sprint operating board

- **Status:** open
- **Observed:** 2026-10-19. The Designer's layout practice alternates direction
  at each level (frames across, sprints down, groups across) but the skill
  stated only the first two levels and forbade wrapping sprints in a parent
  section. A long-running sprint page also improvised an operating board (Now,
  Next, History, Parking lot, with an admission test for parked items) that the
  skill did not describe.
- **Operating correction:** state the alternating axes; allow a tinted
  sprint-group section around related sprints and keep unrelated sprints in
  separate sections; build all studio containers from the Design Studio
  components and tokens. The operating board was withdrawn on 2026-10-22 by
  the Designer, as a second source beside the project's record.
- **Open question:** whether a small test, such as a palette check, may be one
  auto-layout sequence frame or must be one frame per step. Both were used.
- **Close when:** a project page with at least two related sprints is arranged
  as a tinted group section holding stacked sprint sections, with an operating
  board in place, and a page-level review confirms the axes and containment.
